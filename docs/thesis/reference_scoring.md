# 基準データ（参照採点）の作成と、各プロンプトの正確さ

作成: 2026-11-03

採点の「安定性」（同じデータを繰り返し採点したときのぶれ）に加えて「正確さ」を確かめるため、
全15セットについて基準データを作り、各プロンプトの採点（5回の平均）と比べた。

## 1. 作成手順

1. 対象：分析対象の4名・15セット（`stability_experiment.md` の §2.5 と同じデータ。Whisper の書き起こし）。
2. Claude（LLM）が、プロンプト B と同じ手順（下の採点基準）で全箇所を採点し、1箇所ごとに採点根拠を付けた。
   - 4,400行（そのうち数えない箇所の記録が151行）。誤りと判定したのは247箇所。
3. 判断が分かれる箇所（72箇所）に「判断が微妙」の印を付け、研究者がすべて確認した。
   研究者の判断はすべて Claude の判定と一致した（2026-11-03）。
4. これを基準データとした。

**論文での書き方：**「Claude がプロンプト B と同じ手順・採点基準で採点し、判断の分かれる72箇所を研究者が確認したものを基準データとした」。
研究者が全行を確認したわけではないので、「人手採点」とは書かない。基準データ自体も LLM による採点である点は、限界として明記する。

採点データ（参加者の発話を含む Excel）はリポジトリに入れず、研究者が手元で保管している。

## 2. 採点基準（プロンプト B の手順に準拠）

- **手順1 節に分ける：** 主語＋述語動詞1つ＝1節。and / but で動詞が並べば別の節（主語の省略も可）。
  動詞のない断片は節にせず、その中の名詞句も数えない。
- **手順2 言い直し：** 言い直した後の形で節を作り、言い直した要素（前後とも）は数えない。単純な繰り返し・つなぎ言葉も数えない。
- **手順3 節ごとに確認：**
  - 時制：すべての節で1件。述語動詞が話している時間に合っているか。
  - 一致：一般動詞の現在形・am / is / are / was / were・have / has・do / does のときだけ1件。
    過去形の一般動詞・did・助動詞の後の動詞・時制がすでに誤っている動詞は数えない。
  - 名詞：節の中の普通名詞句ごとに1件（固有名詞・曜日・言語名・代名詞・慣用表現の一部は数えない）。冠詞と単数・複数の誤りが誤り。
  - 構文：すべての節で1件。語順、必要な要素の欠落、動詞の後に続く形（前置詞の抜け、to 不定詞と動名詞の取り違えなど）、
    動詞の重複（It's depends 型）、主語の重複、主語と述語の組み合わせ（I felt fun 型）の誤りが誤り。
- 1つの誤りは、最も当てはまる1つの観点にだけ記録する。
- **4観点の対象外（数えない）：** 語の選び方（前置詞の選択など）、意味の矛盾、代名詞の一致（their / its）、聞き取り誤りと考えられる箇所。

## 3. 結果（60セル：4名・15セット × 4観点。各プロンプトは5回の平均）

| 指標 | 現行 | A 定義の明文化 | B 手順の固定 | C 採点例の提示 |
|---|---|---|---|---|
| 平均絶対誤差（pt） | 10.7 | 16.8 | 8.2 | **5.0** |
| 平均の差（＋は AI が厳しい、pt） | +8.3 | +16.8 | +7.9 | **+3.2** |
| 相関係数 r（60セル） | 0.35 | 0.39 | **0.58** | 0.50 |
| 必須文脈数の比（AI ÷ 基準データ） | 0.25 | 0.54 | 0.68 | 0.72 |
| 化石化判定の食い違い（60セル中） | 2 | 11 | **1** | **1** |

観点ごとの平均絶対誤差（pt）：

| 観点 | 現行 | A | B | C |
|---|---|---|---|---|
| 時制 | 9.1 | 3.8 | 4.6 | 2.0 |
| 主語と動詞の一致 | 10.5 | 25.5 | 14.9 | 5.8 |
| 名詞の境界 | 12.0 | 9.9 | 5.1 | 4.5 |
| 構文・語順 | 11.1 | 28.2 | 8.1 | 7.6 |

- 化石化判定は、5回中3回以上「あり」を多数決の判定とした。基準データでは化石化の兆候は1セル（名詞の境界）のみ。
- **読み取り：** C は値の水準が最も基準データに近い。B は観点の高低の並び方（相関）を最もよく捉えるが、全体に厳しく、特に主語と動詞の一致で過剰に検知する。
  A は一致と構文で約2倍に過剰検知した。現行は必須文脈を基準データの約4分の1しか拾っていない。
- **安定性と合わせた結論：** 安定性は B と C が同程度に優れていた（`stability_experiment.md` §2.5）。
  正確さでは、水準は C、相対的な傾向は B が基準データに最も近かった。

## 4. 定性的な観察（化石化の考察の材料）

同じ参加者が、別のセットでも同じ型の誤りを繰り返していた（例：「so ＋ 形容詞 ＋ 名詞」、動詞の重複、
practice の後に to 不定詞、blame の後に前置詞 on、人事分野を指す human resource の単数形）。
具体例と参加者の対応は、研究者が手元の採点データで確認できる（公開リポジトリには載せない）。
